# 简单应用

## 从公式到问题

二次函数的应用题套路：**设未知数 → 列出含 x² 的关系 → 代入或解方程**。

## 例一：代入求值

小球从 20 米高处下落，离地高度 h = 20 - 5t²（米）。

- t = 1 时：h = 20 - 5×1² = 15（米）
- t = 2 时：h = 20 - 5×4 = 0（米），恰好落地

## 例二：面积问题

正方形边长 x，面积 y = x²。x = 7 时 y = 49。

边长增加 2 后为 x + 2，面积 y = (x + 2)²。x = 3 时新边长 5，面积 25。

## 例三：逆向解方程

已知落地时刻求时间：令 h = 0，解 20 - 5t² = 0 → t² = 4 → t = 2（时间取正值）。

## 检验习惯

应用题算完后代回原式检查量纲与合理性（时间、长度不为负），这一步能拦住大部分计算失误。
