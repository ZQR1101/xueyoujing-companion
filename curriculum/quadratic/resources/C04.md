# 顶点式

## 概念

二次函数的**顶点式**：y = a(x - h)² + k，其中 (h, k) 就是顶点坐标。

## 符号陷阱

括号里是 x - h：

- y = (x - 1)² + 2 → 顶点 (1, 2)
- y = (x + 3)² - 1 = (x - (-3))² + (-1) → 顶点 (-3, -1)

“加”变成“减去负数”，横坐标取相反数。

## 系数 a 的作用

a 只影响开口方向与宽窄，**不影响顶点位置**：

y = 2(x - 4)² + 5 与 y = (x - 4)² + 5 的顶点都是 (4, 5)。

## 求值

顶点式中令 x = h，平方项为 0，y = k。

例：y = (x - 2)² + 3，当 x = 2 时 y = 3（正是顶点纵坐标）。
