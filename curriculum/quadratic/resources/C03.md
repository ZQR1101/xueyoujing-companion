# 二次函数图像

## 概念

y = x² 的图像是一条**抛物线**：最低点叫**顶点**，y = x² 的顶点在原点 (0, 0)。

## 基本性质（y = x²）

- x 取任意值时 y ≥ 0；
- x = 0 时 y 最小，等于 0；
- 图像关于 y 轴对称：x = 2 与 x = -2 的 y 值相同（都是 4）。

## 上下平移

y = x² + k 的图像是把 y = x² 向上平移 k 个单位：顶点变为 (0, k)。

例：y = x² + 1 的顶点是 (0, 1)。

## 开口方向

系数 a 决定开口：y = ax² 中 a > 0 开口向上（有最小值）；a < 0 开口向下（有最大值）。

例：y = -x² 的图像与 y = x² 关于 x 轴对称，开口向下。
