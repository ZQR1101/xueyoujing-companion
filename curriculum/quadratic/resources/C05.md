# 开口与对称轴

## 开口方向

y = ax² + bx + c 中，a > 0 开口向上；a < 0 开口向下。|a| 越大，开口越窄。

例：y = -2x² 开口向下；y = x²/2 开口向上且较宽。

## 对称轴

顶点式 y = a(x - h)² + k 的对称轴是直线 **x = h**——它永远经过顶点。

例：

- y = (x - 5)² 的对称轴是 x = 5
- y = 3(x + 2)² - 1 的对称轴是 x = -2（先化成 x - (-2)）

## 易错点

形如 (6 - x)² 的式子：相反数的平方相等，(6 - x)² = (x - 6)²，所以对称轴是 x = 6，不要写成 -6。

## 用途

对称轴把抛物线分成完全相同的两半：左右两侧距离对称轴相等的点，函数值相等。这是后续画图与解方程的基础。
