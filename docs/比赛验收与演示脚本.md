# 比赛验收与演示脚本

## 自动验收入口

```bash
cd backend
.venv\Scripts\python.exe -m pytest tests/test_t14b_reflection.py::test_competition_demo_closed_loop_and_refresh_recovery -q

cd ..\frontend
npm run build
```

完整后端回归：123 项通过。前端生产构建通过。

启动后先访问 `GET /readyz`。返回课程知识点/题目数、RAG 索引版本和 LLM 运行模式；前端顶栏同步显示“Mock · 可重复演示”“在线模型 · 规则回退”或“后端未连接”，避免把离线回退误讲成在线模型。

也可在项目根目录运行 `python scripts/demo_preflight.py`，它只读检查 `/healthz` 与 `/readyz`，不会发送模型请求。

## 3～5 分钟现场流程

1. 在“我的学情”展示诊断结论、证据数量与当前知识点状态。
2. 进入“当前路径”，说明 Planner 同时使用先修图、当前掌握、每日预算、未完成任务、Plan 版本和 active 记忆。
3. 开始今日任务，先故意答错一道题；展示错误证据已记录但未宣称掌握。
4. 请求一级提示；随后打开 AI 概念讲解，展示 RAG 改写查询、课程过滤、重排和真实资料来源。
5. 在提示后答对原题，指出系统明确标记为辅助完成、不计独立掌握。
6. 独立完成迁移题，展示新的有效证据和路径重算。
7. 生成学习反思，展示“已掌握基础 / 仍需巩固 / 本次特点 / 下一次建议”和证据 ID。
8. 刷新页面，证明小结和记忆从 SQLite 恢复；标记一条记忆不准确，展示其从 Planner 默认上下文排除但版本链仍保留。
9. 进入成就激励，展示 25 枚徽章的真实进度、来源事件、任务奖励领取和匿名排行榜。

## 评审映射

- Agent 架构：Coordinator + Planner + L2 版本记忆 + L3 受限上下文 + 工具注册/RAG。
- 自适应策略：有效证据触发重规划；提示/解析/原题重做不虚增掌握；迁移题用于独立验证。
- 完整闭环：诊断、规划、作答、干预、检索、迁移、反思、长期记忆、再规划。
- 创新体验：脚手架辅导、证据透明、可纠错记忆、25 枚真实事件徽章、奖励与匿名排行。
- 稳定性：mock provider 可重复测试；模型失败、推荐失败和记忆失败均有结构化回退。
- 商业价值：首个 B2B2C 校内/教培试点、部署形态、成本公式和 8～12 周验证指标见 [商业化与落地方案](商业化与落地方案.md)，不虚构客户、收入或提分结论。
