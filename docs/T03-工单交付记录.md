## 三、设计说明与合同备注

1. **评分与格式错误**：数值规范化规则随题配置（§8）；提交内容不符合该题配置（如整数题答 "25.5"、表达式 "1+1"、注入串）一律 `AnswerFormatError` → API 层 422 `invalid_request`，不产生评分与证据。已测 `__import__('os')...` 等串不执行任何代码。
2. **数值等价**：rational 类按有理数精确比较，"2/8" 与 "0.25" 均判对 "1/4"；decimal 类按容差（默认 1e-9）。
3. **合同备注（新增字段）**：Question 增加非合同列 `purpose`（screening/practice/transfer/review），依据 §8"每个题族覆盖初筛、练习、迁移和复习用途"；§6 必需字段全部保留。
4. **公开 DTO**：`public_question_dto` 白名单字段输出，测试断言序列化结果不含答案与提示（A15 前置）。
5. 答案核验方式：导入与测试均执行"评分器对标准答案自检必须判对"，24/24 通过；数学内容由本模型按初中二次函数大纲撰写，**建议项目负责人抽检后再用于演示**（规格书要求"人工核验"，当前核验者是执行模型）。
