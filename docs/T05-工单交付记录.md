## 四、设计说明与合同备注

1. **升版判定**：顺序 + 节点状态快照（`Plan.node_status_snapshot`，迁移 0002）双重比对，落实 §9.3"节点状态真正改变才升版"。
2. **任务物化**：每概念 lesson(5min)+practice(5min)；lesson 完成记 `task_completed`（学完讲解即完成，payload 注明 presented）；已完成任务不变，概念掌握/锁定后遗留排队任务自动取消。
3. **合同备注（沿用 R5，无新增修订）**：complete 返回的 plan 自 T05 起为 `policy_version=v1-rules` 正式规则路径（v0-seed 已退役）；T07 的 LLM 只在合法行动集合内选择，不改变规划器职责边界。
4. `GET /goals/{id}/path` 为只读视图：实时重算节点状态，与当前计划不一致时返回 stale=true 与提示（不自动写入，避免读接口写状态）。
