## 三、语义约束

| 约束 | 落实 |

| 不泄露答案/私有提示 | LLM 输入只含公开字段（题面/作答摘要/掌握状态/提示级数）；约束声明「绝不给出答案」；规则回退文案为通用引导 |
| 思路分析不动掌握证据 | 只写 events + llm_usage；测试断言生成前后 mastery 不变 |
| 模型失败/超时/空字段 | 修复一次 → 规则回退（rule_fallback + 原因），HTTP 200 不阻塞 |
| 归属校验 | exercise_owned；学生 B → 404；已关闭题目 → 400 illegal_state |
| 事件留痕 | thinking_submitted / tutor_feedback 事件带 correlation_id，轨迹可回放 |

## 四、重要修复：网关 system prompt 可注入

联调发现 DeepSeek V4-Flash 在 Tutor 任务上 30–40s 才返回且输出成「教学决策」Schema——
根因是 `LLMGateway.decide()` 把「教学决策模块」的 system prompt 写死给了所有调用，
与 Tutor/诊断类任务的输出契约冲突，模型被带偏后长推理。修复：`decide(system=…)` 可注入；
tutoring_agent / diagnosis_report / path_decision 各自传显式契约。
修复后 DeepSeek 对干净指令 3–6s 返回；脏指令 40s 的行为在 90s 超时下实测确认。
