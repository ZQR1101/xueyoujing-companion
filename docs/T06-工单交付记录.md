## 四、设计说明与合同备注

1. **解析内容**：课程包暂无独立解析字段，`solution` 返回 = 标准答案 + 4 级提示拼装的步骤讲解 + 概念标题。**合同备注（R6 建议）**：课程包 v2 为 Question 增加 `private_solution` 字段，可评审后纳入合同。
2. **学习阶段证据语义**（§7.1/§4.2）：错答同样是有效证据（首答无提示）；原题重做/带提示/看解析均不产生独立证据，排除原因分别为 not_first_attempt / hint_used / solution_seen。
3. **next_action 取值**：启用合同 v1.1 R3 预留的 `retry_exercise`；迁移题呈现复用 `next_question`（语义"继续下一题"），未新增枚举。
4. **讲解任务完成语义**：呈现即完成（task_completed payload 注明 presented）；这是首版简化，"学生确认完成"留给 T08 前端交互后评估。
5. 恢复优先级（§9.2 规则 1）：open 练习 > 计划顺序下一任务；讲解通过轻量检索返回概念资源（relevance=1.0）。
