## 四、设计说明与合同备注

1. **修复一次的边界**：网关负责 JSON 解析层的"初始+修复一次"；解析成功但行动/证据/目标不合法时，coordinator 携带错误反馈再调一次；两者均不超过两次模型调用，之后 rule_fallback。
2. **Mock 标记**：离线演练用 mock 提供者的决策 planner_source=llm 但 model_id=mock（§18"可见地标记模拟模型"）；真正不可用时才标 rule_fallback。**备注**：前端 T08 应展示 model_id 与 planner_source。
3. **决策不产生事件**：§11 最小事件集无 decision 事件，决策本体落在 decisions 表（含 evidence_ids 引用），供 decisions 端点与回放使用。
4. **偏好**：§11 的"学生明确偏好"暂无写入端点，build_context 返回空数组占位；T08/T09 增加偏好设置时需合同补端点。
5. **reflection**：小结为确定性规则生成（掌握数/证据数/最近证据 ID），reflection_saved 事件落库；自然语言总结留待在线模式。
6. **finish_session**：当前仅记录决策与回复，不改会话状态；会话完结语义（completed）留待 T08/T09 与演示流程确认后启用。
