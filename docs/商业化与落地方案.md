# 商业化与落地方案（初赛版）

> 本文区分“已经实现”“试点假设”和“后续路线图”。项目当前尚无付费客户、合同收入或经对照实验验证的提分结论，不将计划写成业绩。

## 1. 首个落地场景

首版定位为**初中数学专题课后自适应伴学**，优先面向需要承接课后巩固、错因追踪与个别化辅导的学校和教培机构，采用 B2B2C 路径：教师或机构组织学习，学生使用伴学端完成诊断、规划、练习、辅导与反思。

首个专题选择“二次函数”，不是宣称已经覆盖全学科，而是用 6 个有先修关系的知识点和 300 道核验题验证完整闭环。该边界便于学校低风险试点，也便于测量学习效果和模型成本。

## 2. 用户问题与价值

| 角色 | 当前问题 | 产品价值 | 可验收指标 |
|---|---|---|---|
| 学生 | 不知道薄弱点、不会安排顺序、遇错题容易直接看答案 | 有依据的路径、脚手架提示、跨会话延续 | 完成率、独立首答率、迁移题正确率、连续学习天数 |
| 教师/机构 | 课后个辅成本高，难追溯学生究竟是独立完成还是提示后完成 | 区分独立/辅助证据，保留路径版本和干预记录 | 每生人工复核时长、有效证据覆盖率、异常记录率 |
| 教研人员 | 生成式内容可能越权或无来源 | 课程包、先修图、合法行动集合和 RAG 引用约束 | 引用有效率、非法行动拦截率、规则回退率 |

## 3. 已实现的可交付能力

- 学情诊断：真实答题事件生成掌握估计与可追溯证据。
- 路径规划：先修关系、掌握状态、每日预算、未完成任务和 Plan 版本共同约束。
- 实时干预：苏格拉底式追问、分级提示、查看解析后的迁移题验证。
- 记忆与反思：带 evidence ID 的版本化长期记忆，可纠错、撤销和跨会话读取。
- 课程知识库：结构化课程包、分段资料、双路检索、重排、引用校验与检索轨迹。
- 激励：25 枚按真实事件核发的徽章、积分、任务奖励与匿名排行榜；积分不改变掌握度。
- 稳定性：在线模型异常时显式进入规则回退；Mock 模式可重复演示；`/readyz` 可预检课程、RAG 与模型配置。

## 4. 产品包与部署方式

### 当前可试点产品

“学生伴学端 + 单专题课程包 + 本地/私有数据存储”，适合在一个班或一个校区内进行 8～12 周验证。支持：

- SaaS 试点：由服务方维护应用，学校使用匿名试点账号；
- 私有化试点：应用与 SQLite/后续关系数据库部署在校方指定环境；
- 离线演示：Mock provider 保证不依赖外网，同时明确标注为模拟模型。

### 路线图，不计入当前完成度

- 教师班级看板、作业编排和异常证据复核；
- 更多初中数学专题与经教研审核的课程包；
- 单点登录、组织权限、审计导出和正式多租户；
- 面向大规模部署的 PostgreSQL、任务队列与运行监控。

## 5. 收费假设与成本口径

现阶段不虚构定价。试点后比较以下三种模式，再以真实数据确定报价：

1. 按活跃学生/学期的软件许可；
2. 按校区/学校年度授权，包含限定课程包；
3. 私有化部署费 + 年度维护费 + 可选课程包服务费。

单生活跃成本采用可复算公式，而非预填漂亮数字：

`单生成本 = 模型输入输出费用 + 基础设施摊销 + 课程内容摊销 + 实施与支持成本`

模型调用记录已保存 model、token、耗时与回退信息。试点时以实际调用量和供应商当期价格计算，不把 Mock 数据作为真实成本。

## 6. 8～12 周试点方案

1. 第 1～2 周：学校确认知识范围、匿名化方案、教师审核题库，完成基线测试。
2. 第 3～8 周：一个或两个班使用，每周查看完成率、独立证据、迁移表现、回退率和教师复核时长。
3. 第 9～10 周：进行后测与学生/教师访谈；对照条件由合作学校与研究设计共同确定。
4. 第 11～12 周：形成试点报告，决定扩专题、接教师端或停止。

试点成功门槛需在启动前与校方约定；在获得真实样本前，不宣称提分、减负比例或统计显著性。

## 7. 推广路径

- 第一步：以可演示的二次函数闭环获取学校、教培机构或师范院校教研团队的联合试点。
- 第二步：把经过教师审核的专题制作流程标准化，扩大初中数学覆盖面。
- 第三步：在有留存、学习效果和成本数据后，接入教师看板与组织能力，形成年度授权产品。

核心壁垒不是“接入一个大模型”，而是证据语义、受约束规划、可纠错长期记忆、课程知识库制作规范，以及由真实学习事件积累的可审计闭环。

## 8. 数据安全与风险控制

- 演示只使用虚构学生；不提交真实学生隐私和密钥。
- 学生、课程、会话和 evidence ID 均做归属校验；跨学生访问拒绝。
- LLM 不直接修改掌握度、评分或权威路径，只能在规则产生的合法行动中选择。
- 模型输出异常、超时、伪造引用时显式回退；前端显示当前运行模式。
- 正式进入校园前仍需补齐监护人/学校授权、数据保留周期、删除与导出流程、安全测试和正式隐私文本。

## 9. 当前商业成熟度

当前属于“可运行 Demo + 可设计试点”阶段。已经具备技术闭环、可重复测试和现场演示基础；尚未完成真实客户验证、正式收费、规模化运维和效果实验。因此，初赛商业价值的合理表述是：**落地对象、部署形态、验证指标和扩展路径明确，下一步需要真实试点数据验证付费意愿与教学效果。**
