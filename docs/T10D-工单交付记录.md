## 三、真实数据接入（防"假进度"）

| 元素 | 数据来源 |
|---|---|
| 横幅「已根据 N 条相关作答证据完成分析」、管线步骤1「已采纳 N 题样本」 | `GET /me/overview` 各知识点 `evidence_count` 求和 |
| 证据不足态「已录入 a / 需 3 条有效作答」「目前仅收集到 a 条」 | 已测知识点数（`evidence_count > 0`） |
| 证据不足态清单「XX (已完成) / XX待测」 | 真实概念标题（已测/未测各取前几项） |
| 异常态「已为账号"XX"保留…」 | 演示令牌学生 `display_name` |
| 默认演示状态 | 真实推导：无目标或有效证据 < 2 → 证据不足；否则正常诊断 |
| 开始补测 / 继续答题建立基准 | 导航至既有诊断流程 `/profile/diagnosis`（无目标时先建目标） |
| 直接进入推荐学习 | 导航至今日任务 `/today` |

「演示状态」为页面态切换器（设计稿自带），仅切换本页视图，不改任何业务数据，符合规格书
§18"离线演练须可见标记"（切换器标注「演示状态：」）。
