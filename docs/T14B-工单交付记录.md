# T14-B 工单交付记录

## 交付结论

T14-B 学习反思与记忆更新后端已完成。实现坚持“模型负责表达、规则负责事实”：独立掌握归类只读取后端 `Evidence.eligible`，模型不能新增知识点、证据或改变掌握度、评分和计划。

## 修改文件

- `backend/app/api/dto.py`：反思请求字段。
- `backend/app/api/routers/agent.py`：旧反思接口迁到兼容地址 `/reflection-note`，消除路由冲突。
- `backend/app/api/routers/reflection.py`：T14-B 生成、查询、纠错、撤销、版本链、建议与概览接口。
- `backend/app/services/reflection.py`：事件分类、模型校验、规则回退、版本记忆、建议回退。
- `backend/app/infrastructure/llm/gateway.py`：反思 JSON 的 mock/在线提供者分支。
- `backend/app/services/memory.py`：Planner 只读取当前课程 active 且有证据的记忆。
- `backend/tests/test_t14b_reflection.py`：T14-B 与完整赛事闭环测试。

## 数据模型

- `LearningReflection` 持久化小结、证据摘要、学习特点、建议和回退标记。
- `MemoryFact` 支持 `active / superseded / disputed / invalidated`，并以 `version + supersedes_id` 保留追溯链。
- 原作答、证据和旧记忆均不物理删除。

## 证据处理

- 独立掌握只来自 `Evidence.eligible=true` 的真实作答。
- 提示后答对、查看解析后答对和原题重做不能写成独立掌握。
- 迁移题独立首答可以形成事实。
- 学生自述只进入学习特点辅助上下文，不能单独生成记忆或修改掌握度。
- 模型输出中的证据必须属于当前学生、当前课程、当前会话的允许集合。

## 回退

- LLM 超时/非法 JSON：规则小结，`planner_source=reflection_rule_fallback`。
- 缺失或虚假证据：拒绝模型结果并规则回退。
- 记忆写入失败：保留小结和任务完成状态，返回 `memory_write_status`。
- 推荐失败：返回当前有效 Plan 中仍可执行的任务。
