## 三、真实数据接入

| 元素 | 来源 |
|---|---|
| 今日研习清单 / 剩余时间 | `GET /goals/{id}/tasks` 任务状态映射（completed→已掌握、active→引导中、queued→待开始）、预算-待办 |
| 作答与辅导轨迹 | `GET /exercises/{id}/tutoring-trace`（T12-B），每次动作后刷新 |
| 题目 / 概念章 / 需要巩固 | 会话可恢复练习的公开题目 DTO + 掌握状态（无估计显示「尚未评估」） |
| 温和反馈 / 可能的问题 / 追问 | `POST /exercises/{id}/thinking`（T12-B，真实 DeepSeek） |
| 分级提示 / 提示计数 | `POST /exercises/{id}/hints`（T06），n/4 递进 |
| 重做 / 完整解析 / 迁移引导 | `POST attempts`（订正不计独立证据的说明如实展示）/ `POST solution` |
| 学情通栏 / 为什么给我这个提示 | 掌握估计 + latest_feedback + 提示与证据规则说明（反馈来源标注在线模型或规则回退） |

## 四、与设计稿的有意差异

1. 顶栏沿用全局 TopBar；T12-D 徽标条保留在页面顶部（zip 同位置）。
2. zip 示例中的题目（顶点式求解析式）与 88%/58% 等数字为设计示例；实现按真实题目与掌握数据渲染。
3. 历史提示文本后端不回传（避免重复请求升级提示等级），提示卡显示等级与「继续下一步提示」入口。
