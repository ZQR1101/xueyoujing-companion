## 二、固定管线与规划书逐条对应

| 规划书要求 | 落实 |
|---|---|
| 查询改写（保留原 query、记录 rewritten_query） | 规则改写：原 query + 知识点标题 + error_code 关键词映射；trace 双记录 |
| 混合检索（关键词 + 向量） | 关键词 bigram 覆盖率 + 本地 hashing 向量余弦，0.5/0.5 融合；单臂故障时权重归一化 |
| 去重与重排 | source_id 去重；规则重排（概念匹配 +0.15、内容类型 +0.10，稳定排序）；异常→初始顺序+rag_fallback |
| 课程/知识点/题型过滤 | course_id 必须匹配；concept_id 限定当前任务范围；content_type 严格过滤（为空时放宽并留痕）；hint 类型做答案泄露过滤 |
| 可靠性阈值 | 阈值 0.30；低于阈值 → `no_reliable_source` + “暂时没有找到可靠的课程资料”，不编造 |
| 生成带引用内容 | LLM 只基于过滤后 sources 生成，[n] 标注；引用越界/答案泄露 → 修复一次 → 仍失败禁止展示生成内容，回退为逐字摘录的规则摘要 |
| 保存检索 trace | RagTrace：raw/rewritten query、filters、index_version、candidates、reranked、final_sources、status、耗时、model、fallback_reason、flags |
| 回退链 | 向量失败→关键词（vector_fallback）；两臂均故障→课程包固定资源（retrieve_fallback）；重排失败→rag_fallback；模型超时→结构化错误+规则摘要，不阻塞 |
| 检索分数隔离 | 服务只写 rag_traces/llm_usage，不触碰 Mastery/Evidence/Plan（测试断言 overview 不变） |
| 跨课程资源 | sources/{id} 按课程包可见性过滤，跨课程 → 404 |
