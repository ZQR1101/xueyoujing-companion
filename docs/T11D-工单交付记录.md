## 三、真实数据接入

| 元素 | 来源 |
|---|---|
| 调整前后（原计划/当前安排） | `plan_before / plan_after / selected_action.label` ← POST/GET /goals/{id}/path-decision |
| 调整原因 | 决策 `reason`（真实 DeepSeek 生成） |
| 当前任务 / 预计用时 | `current_task` ← 决策记录 |
| 节点状态与掌握度% | `GET /goals/{id}/path` 节点状态 + `/me/overview` estimate；estimate 为 null 显示「尚未评估」，不画 0 分 |
| Agent 溯源标记 | `Agent {model_id} · {duration_ms}ms`（mock 模拟可见标记；截图示 deepseek-v4-flash · 1047ms） |
| 首次进入自动决策 | GET 404 时以当前计划版本 POST 生成一次（等价用户触发 Agent）；读接口零写入保持 |
| 重新规划 | POST path-decision（expected_version=当前计划版本；409 时提示刷新） |
| 演示状态 | 仅切换页面视图，不改业务数据（zip 自带演示切换器语义） |

## 四、与设计稿的有意差异

1. 顶栏沿用全局 TopBar（T08 体系），演示状态 select 移到页头右侧（zip 在顶栏内），保持全应用一致。
2. zip 内侧栏四项映射到现有路由（学情总览→/profile、错题本与弱项→/today/mistakes、历史规划演进→/path/adjust）。
3. 节点行按真实状态渲染：新学生未测概念显示「尚未评估/待解锁」，不伪造 zip 示例中的 88%/82%；
   掌握后自动呈现对应状态与百分比。
